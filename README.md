Week 1

During the first week, I focused on learning the fundamentals of Splunk and understanding how it is used to collect, search, analyse and visualise machine-generated data. The training introduced me to the Splunk interface, searching techniques, data analysis commands, field extraction and dashboard creation.

I uploaded sample web logs to practise searching through events. I also performed 10 keyword, and wildcard searches to locate specific information within the logs.
Some of the searches included:

error – to find error messages.
failed – to identify failed activities.
login – to find login-related events.
admin – to locate administrator-related activities.
fail* – to find words beginning with fail.
*error* – to find events containing error.
user*	to find terms beginning with user.
"connection refused" to find the exact phrase connection refused.
warning* - to find events containing warning anywhere.


I continued with Splunk Fundamentals and practised using Search Processing Language (SPL) commands to analyse and summarise data.
The commands I worked with included:
This once 
•	stats count by – counts events and groups them according to a selected field.
•	top – identifies the most frequently occurring values.
•	rare – identifies the least frequently occurring values.
•	table – displays selected fields in a table.
•	sort – arranges search results in ascending or descending order.
